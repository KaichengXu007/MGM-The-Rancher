# MGM: The Rancher

一款使用 **Godot 4.7** 开发的俯视角肉鸽地牢游戏。玩家在牧场整备后进入分支地牢，通过战斗、商店、事件与 Boss 战收集遗物与资源；击败怪物可获得怪物蛋，在牧场孵化养殖并产出硬币，并用仓库金币升级永久天赋，形成「地牢冒险 → 基地经营 → 局外养成」的循环。

## 游戏特色

- **主菜单 + 暂停菜单**：新游戏 / 继续游戏 / 退出；游戏中按 `ESC` 暂停，可手动存档或回主菜单
- **本地加密存档**：`user://mtr_save.dat` 持久化仓库、天赋、养殖场状态（里程碑自动存档 + 暂停菜单手动存档）
- **牧场 + 地牢** 双场景循环：基地仓库管理、地牢冒险、回城整备
- **局外天赋树**：消耗仓库金币永久提升生命、攻击、移速（体能特训 / 力量强化 / 迅捷步伐）
- **分支房间机制**：战斗 / 商店 / 事件 / Boss 四种房间，玩家选门决定路线
- **武器系统**：火枪（远程）、太刀（近战三段连击）；可拾取替换，跨场景继承，回牧场重置为火枪
- **数值击退**：武器击退系数 vs 怪物抵抗系数，差值决定击退力度（太刀弹开小怪，Boss 仅轻微震退）
- **伤害飘字**：击中敌人时显示向上飘动的伤害数字
- **7 遗物系统**：加速靴、拳套、飞镖、分裂箭、阿瓦隆、精灵球、锁甲等（部分遗物按武器类型生效）
- **商店房**：5 个商品格——血包（2 金币，恢复 50% 最大生命）+ 4 个随机未拥有遗物（6 金币）
- **事件房**：老虎机（金币抽奖）、血祭坛（扣血换随机遗物）
- **怪物蛋孵化与养殖**：小怪/Boss 概率掉落对应怪物蛋；牧场右上角养殖场最多同时孵化 5 颗蛋，孵化后友好怪物定时产币
- **独立掉落概率**：怪物蛋、小硬币、大硬币各自判定，互不影响
- **金币统一结算**：拾取硬币后自动折算为背包金币，回牧场时存入仓库

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | `W` `A` `S` `D` |
| 瞄准 | 鼠标 |
| 攻击 | 鼠标左键（按住连发） |
| 交互 | `E`（仓库、老虎机、天赋终端、养殖场收获等） |
| 确认 | `F`（传送门、分支门、遗物拾取、商店购买、养殖场孵蛋） |
| 暂停 | `ESC`（打开暂停菜单；背包/仓库 UI 打开时 ESC 关闭 UI） |

### 主菜单

| 按钮 | 说明 |
|------|------|
| 继续游戏 | 读取本地存档，进入牧场（无存档时隐藏） |
| 新游戏 | 重置全部进度并覆盖存档，进入牧场 |
| 退出游戏 | 退出程序 |

### 暂停菜单（`ESC`）

| 按钮 | 说明 |
|------|------|
| 继续游戏 | 关闭暂停菜单 |
| 保存游戏 | 将背包金币与物资存入仓库并写入本地存档 |
| 回到主菜单 | 自动存档后返回主菜单 |

### 牧场

| 地点 | 操作 |
|------|------|
| 仓库 | 靠近后按 `E` 打开，背包与仓库互转物品 |
| 天赋终端 | 靠近后按 `E` 打开天赋树，消耗仓库金币升级 |
| 地牢入口 | 靠近传送门按 `F` 进入地牢 |
| 养殖场（右上角） | `F` 放入怪物蛋孵化；`E` 一键收获友好怪物产出的硬币 |
| 背包（HUD 按钮） | 查看随身物品与当前属性（生命/护甲/移速/攻击） |

## 地牢进度

- 共 **3 个大关（Act）**，每关 **8 个房间**
- 房间 1–6：随机 2–3 扇分支门（战斗 / 商店 / 事件）
- 房间 7：Boss 门
- 房间 8：Boss 战；通关第 3 大关后回牧场

## 怪物与养殖

| 怪物 | 蛋名称 | 孵化时间 | 产出 | 击退抵抗 |
|------|--------|----------|------|----------|
| 小怪1 | 怪物蛋（小怪1） | 30 秒 | 小硬币 | 0.1 |
| Boss1 | 怪物蛋（Boss1） | 60 秒 | 大硬币 | 0.2 |

- 小怪约 20% 概率掉落对应蛋（精灵球遗物 +25%）；Boss 同理
- 蛋可存入仓库，在养殖场消耗并孵化；已孵化怪物在离开牧场后仍会保留

## 武器击退

| 武器 | 击退系数 | 对小怪 (抗 0.1) | 对 Boss (抗 0.2) |
|------|----------|-----------------|------------------|
| 火枪 | 0.1 | 无（系数未超过抵抗） | 无 |
| 太刀 | 0.3 | 明显弹开 | 轻微震退 |

## 天赋树（局外养成）

| 天赋 | 效果 | 满级 | 基础花费 |
|------|------|------|----------|
| 体能特训 | 初始最大生命 +10 | Lv.5 | 50 金币 |
| 力量强化 | 所有武器攻击 +2 | Lv.5 | 80 金币 |
| 迅捷步伐 | 基础移速 +5% | Lv.3 | 100 金币 |

升级花费随等级递增（`base_cost × multiplier^当前等级`）。金币存储在**仓库**的 `gold` 条目中。

## 存档说明

**自动存档触发点：**

- 升级天赋、回牧场结算、养殖场放蛋/收获/孵化完成
- 暂停菜单「回到主菜单」、新游戏覆盖存档

**手动存档：** 暂停菜单 → 「保存游戏」

**存档内容：** 仓库物品与金币、天赋等级、孵化中/已孵化怪物

**存档位置：** `user://mtr_save.dat`（加密）。可在 Godot 编辑器 **项目 → 打开用户数据文件夹** 中查看或删除。

## 运行方式

1. 安装 [Godot 4.7](https://godotengine.org/)（或兼容的 Godot 4.x）
2. 用 Godot 打开 `MTR/project.godot`
3. 按 **F5** 运行，主场景为 `MainMenu.tscn`

## 技术说明

- 渲染：GL Compatibility
- 全局单例：`GlobalManager` 管理仓库、局内背包、遗物、关卡进度、孵化状态、天赋与加密存档
- 存档：`FileAccess.open_encrypted_with_pass` + `var_to_str` / `str_to_var` 保留原生类型
- 地牢换房通过 `reload_current_scene()` 实现，局内进度（房间、遗物、背包）不写入存档
- 击退：`weapon_knockback > knockback_resistance` 时施加 `(差值 × 800)` 像素/秒的瞬时推力，带阻尼衰减
