# MGM: The Rancher

一款使用 **Godot 4.7** 开发的俯视角肉鸽地牢游戏。玩家在牧场整备后进入分支地牢，通过战斗、事件与 Boss 战收集遗物与资源，再带回基地仓库。

## 游戏特色

- **牧场 + 地牢** 双场景循环：基地仓库管理、地牢冒险
- **分支房间机制**：战斗 / 商店 / 事件 / Boss 四种房间，玩家选门决定路线
- **7 遗物系统**：加速靴、拳套、飞镖、分裂箭、阿瓦隆、精灵球、锁甲等
- **事件房**：老虎机（金币抽奖）、血祭坛（扣血换随机遗物）
- **独立掉落概率**：怪物蛋、小硬币、大硬币各自判定，互不影响
- **金币统一结算**：拾取硬币后自动折算为背包金币

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | `W` `A` `S` `D` |
| 射击 | 方向键 ↑ ↓ ← → |
| 交互 | `E`（仓库、老虎机等） |
| 确认 | `F`（传送门、遗物拾取、分支门） |

## 地牢进度

- 共 **3 个大关（Act）**，每关 **8 个房间**
- 房间 1–6：随机 2–3 扇分支门（战斗 / 商店 / 事件）
- 房间 7：Boss 门
- 房间 8：Boss 战；通关第 3 大关后回牧场

## 项目结构

```
MTR/
├── ranch.tscn          # 牧场主场景
├── dungeon.tscn        # 地牢主场景
├── global_manager.gd   # 全局状态（Autoload）
├── player/             # 玩家
├── enemy/              # 小怪
├── boss/               # Boss
├── bullet/             # 子弹
├── relic/              # 遗物拾取
├── drop_item/          # 掉落物
├── portal/             # 传送门、分支门
├── events/             # 事件房（老虎机、血祭坛）
├── environment/        # 房间边界墙
├── warehouse/          # 基地仓库
└── ui/                 # HUD、背包、仓库 UI
```

## 运行方式

1. 安装 [Godot 4.7](https://godotengine.org/)（或兼容的 Godot 4.x）
2. 用 Godot 打开 `MTR/project.godot`
3. 按 **F5** 运行，主场景为 `ranch.tscn`

## 技术说明

- 渲染：GL Compatibility
- 全局单例：`GlobalManager` 管理仓库、局内背包、遗物、关卡进度与跨房间血量/护甲
- 地牢换房通过 `reload_current_scene()` 实现，关键状态保存在 `GlobalManager`
